# SceneryBlade

**布景之杖** —— 拔刀剑（SlashBlade: Resharped）附属，面向 Minecraft **1.21.1 / NeoForge**。

以达妮娅与爱弥斯为主题，新增两条命名刀线、两式剑技与 SA 充能体系、一套铁砧强化体系，以及一个可叠层的聚爆特效。

## 两条刀线

每线三把，沿「潮汐 → 下位刀 → 最终刀」逐级进阶，每级都是**用上一级作为材料**、并满足对应的击杀数要求：

| 阶段 | 布景之杖线（达妮娅） | 启明星线（爱弥斯） | 进阶条件 |
| --- | --- | --- | --- |
| 起点 | 潮汐 | 潮汐 | 合成（蓝染料 + 铁锭 + 蓝色羊毛 + 白鞘） |
| 下位 | 残景之杖 | 启明星 | 用潮汐 → **100 击杀**（+ 樱花树苗 / 铁锭 / 青金石） |
| 最终 | **布景之杖 ★达妮娅★** | **永远的启明星** | 用下位刀 → **1000 击杀 + 20000 耀魂** |

| --- | ---: | ---: | --- | --- |
| 潮汐 | 7 | 120 | 波刃 | — |
| 残景之杖 | 10 | 200 | 波刃 | — |

两把最终刀自带满档附魔（力量 X、锋利 V、亡灵杀手 X、抢夺 VII、耐久 III）。

### 剑技

剑技**长按右键释放**，不占用额外按键。

- **蚀域**（布景之杖）—— 在脚下展开半径 **10 格**的领域，持续 **30 秒**：每秒对范围内敌人造成 **3 点无视护甲**的魔法伤害，且只打敌对生物与正在攻击玩家的生物；展开瞬间随机播放一句语音。
- **永远的启明星**（永远的启明星专属）—— 在准星方向 3 格处召出巨剑，自 **30 格**高空以 **1 秒**落地，做**一次**半径 **10 格**的范围伤害（伤害 = 释放瞬间刀攻击力 × **3.4**，无视护甲），随后插在原地停留 **5 秒**；落地**不叠加聚爆层数**。

### SA 充能

剑技不再「冷却到点就能放」，而是各自攒一条充能：**攒满才能放，放完清空**。

| 项 | 数值 |
| --- | --- |
| 充满所需 | **125**（按剑技分别配置） |
| 命中 / 击杀 / 受到伤害 | +3 / +15 / +2 |
| 自然回复 | **无**，只能靠战斗行为累积 |

- 充能**只在手持对应那把刀时**累积，不会衰减，跨战斗持久保存；
- **未攒满时长按右键不会空放**：剑技自动换成内置的**幻影刃**，并在动作栏提示当前充能百分比；
- 屏幕**右下角**常驻一条充能环，显示当前手持刀的图标与进度，充满时高亮脉动；手持其它物品时不显示。

### 暴击

**两把最终刀**（布景之杖、永远的启明星）自带暴击特性：未强化时即为 **20% / 150%**，经回音频段强化后最高 **80% / 280%**；触发时按暴击伤害倍率结算这一发伤害，并伴随原版暴击粒子与音效。只在这两把刀**主手**手持时触发，不会外溢到其它武器，下位刀不具备该特性。

## 回音频段强化

**达妮娅的回音频段**强化布景之杖线，**爱弥斯的回音频段**强化启明星线，效果一致。

在铁砧上每次消耗 **1 个回音频段 + 5 级经验**，最多强化 **6 次**：

| 项目 | 初始 | 满级（6 级） |
| --- | ---: | ---: |
| 基础攻击力 | — | **+90%**（每级 +15%） |
| 暴击率 | 20% | **80%** |
| 暴击伤害 | 150% | **280%** |

攻击力按基础值线性叠加，暴击率与暴击伤害同样线性增长。刀的 Tooltip 会显示当前强化进度：基础暴击面板显示在「在主手时」属性区，强化带来的增量显示在强化区块。

> 注意：强化等级记在刀自身的物品数据上，而拔刀剑的进阶配方只会转移**耀魂数、击杀数与锻造值**，
> 因此**用下位刀合成最终刀时，已投入的回音频段强化不会带过去**。

## 聚合·聚爆

命中目标时叠层，**层数达到上限即引爆**，随后清零、重新从 1 层叠起。

- 默认叠满 **10 层**引爆；手持**永远的启明星**时上限提升到 **13 层**，且**第 6 层即提前引爆**。
- 提前引爆**不会削弱伤害** —— 结算时取的是层数上限，而非引爆瞬间的实际层数。
- 伤害**无视护甲**（走原版魔法伤害）。基础伤害 = 施术者**最大生命值 × 0.25 + 当前护甲值 × 0.5**，
  以 10 层为 1.0 倍基准，每多 3 层翻一倍。
- 层数记在目标身上；**15 秒**内没有再叠层，则每 15 秒衰减 1 层。

装了 Jade 时可直接看到当前层数与下次衰减时间。

## 铁魔法联动

安装 Iron's Spells 'n Spellbooks 后：

- 每把刀会**自带本线法术**（布景之杖线为火焰箭、启明星线为烈焰冲锋），
  最终刀为高等级、下位刀为低等级，可在奥术铁砧上继续改写。
- 手持刀时获得**炽焰法术强度 / 法术强度 / 法力值恢复 / 最大法力值**加成（只在主手生效）：
  下位刀 +15% / +5% / +25% / +150，最终刀 +30% / +10% / +50% / +300。

未安装铁魔法时本模组照常运行，这部分内容不会出现。
