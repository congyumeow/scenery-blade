# SceneryBlade

**布景之杖** —— 拔刀剑（SlashBlade: Resharped）附属，面向 Minecraft **1.20.1**。
同一个 jar **同时支持 Forge 与 NeoForge** 1.20.1（两者的装载器 modId 都是 `forge`，
且 NeoForge 47.x 就构建在 Forge 47.x 之上），无需分别构建。

以达妮娅、爱弥斯与卡提希娅为主题，新增三条命名刀线与一条分支刀组、一套铁砧强化体系、
两种可叠层的持续伤害特效，以及一个可进出的虚质空间维度。

| 可选 | [Jade](https://modrinth.com/mod/jade) —— 显示聚爆与风蚀的层数 |

### 拔刀剑版本适配

待机刀渲染方法 `renderHotbarItem` 的位置随拔刀剑版本变化：1.20.1 线的 **1.9.65** 里它就在
`LayerMainBlade` 上；1.21.1 线的拔刀剑从 **2.0.8** 起把它上移到了父类 `LayerSlashBlade`
（2.0.8 / 2.1.9 均已确认）。

本模组对两条路径**各准备了一份注入**，实际只会命中一条，因此不会因为上游换类名而崩在
`InvalidInjectionException` 上。代价是反过来的：注入失败时修复会**安静失效**
（最多留一行 DEBUG 日志）而不是让游戏加载失败 —— 排查「副手没装备却显示待机刀」时，
先看日志里注上了哪个目标类。

## 刀线

### 布景之杖线（达妮娅）与启明星线（爱弥斯）

每线三把，沿「潮汐 → 下位刀 → 最终刀」逐级进阶，每级都是**用上一级作为材料**、
并满足对应的击杀数要求：

| 阶段 | 布景之杖线 | 启明星线 | 进阶条件 |
| --- | --- | --- | --- |
| 起点 | 潮汐 | 潮汐 | 合成（蓝染料 + 铁锭 + 蓝色羊毛 + 白鞘） |
| 下位 | 残景之杖 | 启明星 | 用潮汐 → **100 击杀**（+ 樱花树苗 / 铁锭 / 青金石） |
| 最终 | **布景之杖 ★达妮娅★** | **永远的启明星** | 用下位刀 → **1000 击杀 + 20000 耀魂** |

### 不屈命定之冠线（卡提希娅）

同一把潮汐分出的三条支线，**三把下位刀全部练成后合为毕业刀**：

| 阶段 | 刀 | 进阶条件 |
| --- | --- | --- |
| 起点 | 潮汐 | 同上 |
| 下位（三选三） | 奥特尔 / 提尔芬 / 赫格利 | 各用潮汐 → **100 击杀**（青金石 / 紫水晶 / 红石 等） |
| 最终 | **不屈命定之冠** | 三把下位刀各 **333 击杀** + **卡提希娅的回音频段** |

### 剑技

- **蚀域**（布景之杖）—— 展开领域，持续侵蚀范围内目标。
- **永远的启明星**（永远的启明星）—— 召出巨剑实体进行打击。
- **潮怒风哮之刃**（不屈命定之冠）—— 前方长方形的范围斩击，命中即叠风蚀。

三者都有充能过程，HUD 上会显示进度；未充满时剑技被替换为内置幻影刃。

## 回音频段强化

**达妮娅的回音频段** → 布景之杖线，**爱弥斯的回音频段** → 启明星线，
**卡提希娅的回音频段** → 不屈命定之冠。三条线效果一致。

在铁砧上每次消耗 **1 个回音频段 + 5 级经验**，最多强化 **6 次**：

| 项目 | 初始 | 满级（6 级） |
| --- | ---: | ---: |
| 基础攻击力 | — | **+90%**（每级 +15%） |
| 暴击率 | 20% | **80%** |
| 暴击伤害 | 150% | **280%** |

攻击力按基础值线性叠加，暴击率与暴击伤害同样线性增长。刀的 Tooltip 会显示当前强化进度。

> 注意：强化等级记在刀自身的物品数据上，而拔刀剑的进阶配方只会转移**耀魂数、击杀数与锻造值**，
> 因此**用下位刀合成最终刀时，已投入的回音频段强化不会带过去**。

## 两种叠层特效

### 聚合·聚爆（布景之杖 / 永远的启明星）

命中目标时叠层，**层数达到上限即引爆**，随后清零、重新从 1 层叠起。

- 默认叠满 **10 层**引爆；手持**永远的启明星**时上限提升到 **13 层**，且**第 6 层即提前引爆**。
- 提前引爆**不会削弱伤害** —— 结算时取的是层数上限，而非引爆瞬间的实际层数。
- 伤害**无视护甲**（走原版魔法伤害），数值与施术者的**最大生命值**和**当前护甲值**相关；
  以 10 层为 1.0 倍基准，每多 3 层翻一倍。
- 层数记在目标身上；**15 秒**内没有再叠层，则每 15 秒衰减 1 层。

### 风蚀（不屈命定之冠）

用不屈命定之冠造成伤害时给目标叠层，层数做成真正的药水效果，**每 3 秒结算一次持续伤害**。

- 平时上限 **3 层**；手持不屈命定之冠时上限提升到 **6 层**。
  换下刀后已叠的层数会被削回 3 层。
- 伤害按**施术者**的生命与护甲结算（与聚爆同源公式，3 层 = 聚爆 10 层 = 1.0 倍）。
- **每 15 秒衰减 1 层**，归零则效果消失。

装了 Jade 时两种特效的层数与下次衰减时间都能直接看到。

## 虚质空间

新增一个数据驱动的维度（末地类环境、超平坦、地基为 3 层虚质方块）：

- 手持**任一毕业刀**（布景之杖 / 永远的启明星 / 不屈命定之冠）时，按 **`'`**（单引号，
  可在「选项 → 控制 → 按键绑定」改键）进出虚质空间。
- **同一个按键负责进入与离开**；返回点（维度 + 坐标 + 朝向）记在玩家身上，
  从哪个维度进的就回哪个维度。
- 再次进入会落回**上次离开时在空间内的位置**，第一次才用固定出生点。

## 铁魔法联动

安装 Iron's Spells 'n Spellbooks 后：

- 每把刀会**自带本线法术**：布景之杖线火焰箭、启明星线烈焰冲锋、不屈命定之冠**闪电球**；
  毕业刀为高等级、下位刀为低等级，可在奥术铁砧上继续改写。
- 手持刀时获得**学派法术强度 / 通用法术强度 / 法力回复 / 最大法力**加成，毕业刀数值翻倍。
  学派跟着刀走：不屈命定之冠给**雷霆**法术强度，其余给**火焰**法术强度。

未安装铁魔法时本模组照常运行，这部分内容不会出现。
